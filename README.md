# melanopsin-paper

Code used to analyze data and generating the figures in the paper ().

## Python code

To run the python code open the repo in a devcontainer in vscode, more info here (https://code.visualstudio.com/docs/devcontainers/containers). 
Then install the python packages using
```
pip install python/requirements.txt
```
The analysis can then be replicated by running the notebook python/calcium_signal_analysis.ipynb.
